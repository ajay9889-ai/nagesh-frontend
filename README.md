# Nagesha R — Portfolio Frontend

Production developer portfolio for **Nagesha R** — Full-Stack Developer & AI Systems Engineer specializing in Machine Learning, Deep Learning, Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), Agentic AI Workflows, and scalable backend architectures.

---

## ⚡ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack, React 19)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with responsive editorial design system
- **Typography**: Syne (Headings & Display), Instrument Sans (Body), Caveat (Signature Script)
- **Animation & Motion**: Custom cursor, interactive color-reveal portrait mask, Lenis smooth scrolling, CSS marquee
- **State & Theme**: Dynamic light / dark mode toggle with persistent local storage
- **Interactive Tools**: `Cmd + K` Command Palette, live reaction metrics, contact messaging
